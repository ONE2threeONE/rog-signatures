# rog-signatures

Image assets for Realty ONE Group agent email signatures, served over GitHub Pages so
they load from any mail client, including Outlook, which cannot use embedded images.

One folder per agent. Each holds the circle-cut headshot (PNG with transparency, so it
stays round everywhere) and the official ROG wordmark.

Built and maintained from `~/Desktop/Signatures/` on Brian's Mac. Do not edit here;
rerun the agent's `build.py` and push the result.
